================================================================================
                        INSTALLATION STEPS
================================================================================

STEP 1: EXTRACT FLUTTER
------------------------
1. Open: C:\Users\Arjun\Downloads\
2. Find: flutter_windows_3.24.5-stable.zip
3. Right-click → "Extract All..."
4. Extract to: C:\ (just C drive, it will create C:\flutter folder)
5. Result: You'll have C:\flutter\ with bin, packages folders inside

STEP 2: ADD FLUTTER TO PATH
---------------------------
1. Press Windows key + X
2. Click "System"
3. Click "Advanced system settings" (on the right)
4. Click "Environment Variables" button (at bottom)
5. Under "User variables" section:
   - Find and click "Path"
   - Click "Edit"
   - Click "New"
   - Type: C:\flutter\bin
   - Click OK
   - Click OK
   - Click OK
6. IMPORTANT: Close ALL PowerShell/Terminal windows
7. Open NEW PowerShell

STEP 3: VERIFY FLUTTER
----------------------
Open PowerShell and type:

   flutter doctor

You should see something like:
   [✓] Flutter (Channel stable, 3.24.5)

STEP 4: INSTALL ANDROID STUDIO
------------------------------
Download: https://developer.android.com/studio

1. Run the installer
2. Click "Next" through all steps
3. Install all components (accept defaults)
4. Wait for Android SDK to download (~2.5 GB)
5. Installation takes 15-20 minutes

STEP 5: ACCEPT LICENSES
-----------------------
Open PowerShell and run:

   flutter doctor --android-licenses

Press 'y' to accept all licenses (there are about 7 of them)

STEP 6: BUILD YOUR APK
----------------------
Open PowerShell and run these commands:

   cd C:\Users\Arjun\OneDrive\Desktop\GAMES.APP\flutter_games
   flutter pub get
   flutter build apk --debug

First build takes 10-15 minutes (be patient!)
You'll see progress messages, don't interrupt it.

================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: "flutter is not recognized"
SOLUTION: 
- Flutter not in PATH or PowerShell not restarted
- Try: C:\flutter\bin\flutter doctor
- Or: Restart PowerShell after adding PATH

PROBLEM: "Android SDK not found"
SOLUTION:
- Install Android Studio first
- Run: flutter doctor --android-licenses

PROBLEM: "cmdline-tools component is missing"
SOLUTION:
1. Open Android Studio
2. Tools → SDK Manager
3. SDK Tools tab
4. Check "Android SDK Command-line Tools"
5. Click Apply

PROBLEM: Build is stuck or very slow
SOLUTION:
- First build always takes 10-15 minutes (this is NORMAL!)
- Don't cancel it, just wait
- Subsequent builds will be much faster (1-2 minutes)

PROBLEM: "Gradle build failed"
SOLUTION:
- Make sure you're connected to internet
- Try: flutter clean
- Then: flutter pub get
- Then: flutter build apk

PROBLEM: Java/JDK errors
SOLUTION:
- Android Studio includes JDK
- Make sure Android Studio installation completed fully
